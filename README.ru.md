# 🛡️ Security Header Checker

> Мощный CLI инструмент для анализа заголовков безопасности веб-сайтов

[![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![Version](https://img.shields.io/badge/Version-0.0.4-orange.svg)](ROADMAP.md)

[English](Readme.md) | [Русский](README.ru.md)

## ✨ Возможности

- 🔒 **Анализ заголовков безопасности** - Проверка 15+ критических заголовков
- 🚀 **Массовая проверка** - Параллельная обработка множества сайтов
- 🔐 **SSL/TLS анализ** - Детальная проверка сертификатов и шифрования
- 📡 **Анализ ответов** - HTTP статус коды и информация о сервере
- 🎨 **Красивый вывод** - Цветной терминальный интерфейс
- 💾 **Экспорт результатов** - TXT, JSON, CSV форматы

## 🚀 Быстрый старт

```bash
# Установка
pip install -r requirements.txt

# Проверка одного сайта
python main.py https://example.com

# Массовая проверка
python main.py --file urls.txt --parallel 5

# Полный анализ
python main.py https://example.com --ssl-check --response-analysis
```

## v0.0.4: установка и поведение

Целевая поддержка: Python 3.10–3.14. Создайте отдельное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --version
```

На Linux: `.venv/bin/python -m pip install -r requirements.txt`.

`--ssl-only` и `--response-only` запускают только выбранный модуль и
взаимоисключают друг друга. `--batch-size` ограничивает число сайтов в пакете,
`--parallel` — число работников; timeout и числовые лимиты должны быть положительными.
Редиректы по умолчанию не выполняются; включите `--follow-redirects` при необходимости.
`--no-verify-ssl` отключает проверку сертификата только для HTTP-запросов;
TLS-анализ независимо проверяет доверие и hostname.

TXT показывает включённые проверки; JSON сохраняет составной отчёт целиком;
CSV содержит колонки URL, Module, Check, Value, Status, Score, Error.
Частичные результаты сохраняются даже при ошибке одного модуля.
Код завершения: 0 — все выбранные проверки и экспорт выполнены,
1 — ошибка проверки или экспорта, 2 — неверные аргументы CLI.

Оценка — собственная эвристика, а не отраслевой стандарт или полный аудит.
CSP/HSTS/cookies разбираются структурно; остальные заголовки пока используют базовые правила. TLS UNKNOWN означает
невозможность достоверной проверки; анализируется только согласованный cipher suite.
Недоверенный сертификат может отображаться, но не получает статус verified.

Тесты, настройки pytest и запускающий их CI удалены по просьбе пользователя.
Автоматические проверки в текущую поставку не входят.

## Что изменилось в 0.0.4

- **HSTS: 0/5/10 баллов.** Неверный, повторный или нулевой max-age и
  HSTS на HTTP получают 0; срок менее года — 5; не менее года — 10.
  includeSubDomains и preload необязательны и показываются отдельно.
- **CSP: до 15 баллов.** До 9 за ограничения скриптов, по 3 за object-src
  и base-uri. Анализ учитывает наследование директив, nonce/hash и
  strict-dynamic. Их наличие не доказывает корректность содержимого страницы.
  Report-only — диагностика. При нескольких enforced-политиках их совместное
  действие не оценивается: CSP получает INFO и исключается из знаменателя.
  Замечания к отдельным политикам не являются выводом об их совместной защите.
- **Cookies: до 4 баллов.** Проверяется каждая строка Set-Cookie, а итог
  определяется худшей применимой cookie. Без Secure — 0; с отсутствующим
  или неверным SameSite — максимум 2; без HttpOnly — максимум 3.
  SameSite=None с Secure допустим; отсутствие HttpOnly может быть намеренным.
  Отсутствие cookies и корректное удаление cookie не штрафуются.

GOOD — соответствие текущим правилам; WARNING — недостаток или контекстное
предупреждение; BAD — ошибка либо опасное/недостаточное разрешение;
INFO — пояснение или отсутствие общей оценки. Неприменимые проверки исключаются
из max_score; при нулевом знаменателе выводится N/A. Баллы разных версий или
разных наборов применимых правил напрямую не сопоставимы.

Существующие поля JSON сохранены; добавлены final_url, header_values, percentage и детали
findings / parsed / applicable, а для cookies — список cookies. CLI, TXT и CSV
показывают причины и рекомендации. В CSV прежние колонки сохранены; отдельные
строки cookies имеют имя и порядковый номер. Новых CLI-флагов нет.

Пример просмотра рекомендаций и экспорта:

```bash
python main.py https://example.com --follow-redirects --verbose --output report.json
```

Для v0.0.4 выполнен только просмотр изменений, ссылок, версий и форматирования
diff. Тесты и проверки выполнения программы не запускались по просьбе пользователя.

| **X-Powered-By** | Технологии сайта | 2 |
| **Cache-Control** | Политика кэширования | 3 |
| **Set-Cookie** | Безопасность куки | 4 |
| **Clear-Site-Data** | Очистка данных | 3 |
| **Cross-Origin-Embedder-Policy** | Cross-origin embedder policy | 3 |
| **Cross-Origin-Opener-Policy** | Cross-origin opener policy | 3 |
| **Cross-Origin-Resource-Policy** | Cross-origin resource policy | 3 |
